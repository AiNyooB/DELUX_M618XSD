# Delux M618XSD 驱动功能 Wiki

> **产品型号**：M618XSD（SEEKER 系列垂直鼠标）  
> **真实型号**：LXD-001  
> **USB 标识**：VID `0x1D57` / PID `0xFA60`  
> **驱动文件**：`Mouse.exe` + `hiddriver_ms_4.dll`（HID 传输层）  
> **配置页面**：MS_4（驱动内 5 款设备中第 4 个标签页）  
> **协议文档**：同目录 `HID协议逆向报告.md`（基线为静态推断，关键 Report 已实机验证，详见各节 ✅ 标记）、`AGENTS.md`（可信度分级）

---

## 一、驱动功能总览

驱动软件共包含 **9 个功能模块**：

| # | 模块名称 | 可见性 | 说明 |
|---|---------|--------|------|
| 1 | 按键设定 | ✅ | 10 个可编程按键，默认功能分配 |
| 2 | DPI 设定 | ✅ | 5 档可调 DPI，范围 40-4800 |
| 3 | 灯光设定 | ✅ | 5 种灯效模式 + 速度调节 + 自动感应灯 |
| 4 | 回报率设定 | ✅ | 4 档轮询率（125/250/500/1000 Hz） |
| 5 | 按键响应时间 | ✅ | 去抖动滑块，1-25ms 可调 |
| 6 | 电池显示 | ✅ | 实时电量百分比 |
| 7 | 电源管理 | ✅ | 一级休眠 + 睡眠时间 |
| 8 | 宏管理器 | ✅ | 录制/编辑宏，绑定到按键（详见第十章） |
| 9 | 配置管理（Profile） | ✅ | 多套配置方案切换（详见第十一章） |

## 三、DPI 设定

### 3.1 基本参数

| 项目 | 值 |
|------|-----|
| 可调档位数 | 5 档 |
| DPI 范围 | 40 ~ 4800 |
| 默认档位 | 800 / 1200 / 1600 / 2400 / 4000 |

### 3.2 默认 DPI 档位

| 档位 | 默认值 | 指示灯颜色 |
|------|--------|-----------|
| DPI 1 | 800 | 红色 |
| DPI 2 | 1200 | 绿色 |
| DPI 3 | 1600 | 蓝色 |
| DPI 4 | 2400 | 紫色 |
| DPI 5 | 4000 | 黄色 |


### 3.3 操作方式

- **滑块调节**：每个 DPI 档位有独立的垂直滑块（min=40, max=4800）
- **手动输入**：滑块下方的文本框可直接输入 DPI 值（最多 5 位数字）
- **档位启用**：每个档位有单选框控制是否启用该档位
- **应用按钮**：修改挡位值后点击「应用」挡位值生效

### 3.4 XML 对应关系

```
DPI 容器：ms_4_ver_dpi
单个 DPI 档位：ms_4_ver_dpi_N（N = 1-8）
DPI 滑块：ms_4_slider_dpi_N
DPI 输入框：ms_4_edit_dpi_N
DPI 颜色按钮：ms_4_btn_dpi_color_N
DPI 档位启用：ms_4_check_dpi_step_N
应用按钮：ms_4_btn_apply_dpi
重置按钮：ms_4_btn_reset_dpi（隐藏）
```

## 四、灯光设定

### 4.1 灯效模式

驱动提供 **5 种灯效模式**（主界面下拉框可见）：

| 编号 | 模式名称 | 说明 |
|------|---------|------|
| 1 | 关闭 | LED Off |
| 2 | 呼吸 DPI | 单色呼吸灯效 |
| 3 | 常亮 DPI | 单色常亮灯效 |
| 4 | 循环呼吸 | 多色循环呼吸 |
| 5 | 霓虹 | Neon 彩虹灯效 |


### 4.2 可调参数

| 参数 | 控件 | 范围 | 说明 |
|------|------|------|------|
| 模式 | 下拉框 | 5 种 | 灯效模式切换 |
| 速度 | 滑块 | 1 ~ 8 级 | 呼吸/循环速度 |
| 移动关灯 | 复选框 | 开/关 | 手移动鼠标时关闭 RGB 灯效 |



### 4.4 XML 对应关系

```

模式下拉框：ms_4_combo_light

```

## 六、按键响应时间（去抖动）

### 6.1 参数

| 项目 | 值 |
|------|-----|
| 范围 | 1 ~ 50 ms |
| 默认值 | 6 ms（截图显示） |
| 控件 | 水平滑块 + 数值显示框 |

### 6.2 说明

按键去抖时间（Key Debounce）越短，按键响应越快，但可能增加误触概率；越长则更稳定但延迟增加。

### 6.3 XML 对应关系

```
容器：ms_4_hor_key_debounce
滑块：ms_4_slider_key_debounce（min=1, max=25）
数值标签：ms_4_label_key_debounce
```

### 7.2 参数

|------|-----|
| 电池容量 | 1000 mAh 锂电池 |
| 显示方式 | 进度条（0-100%） |

### 7.3 XML 对应关系


## 八、电源管理

### 8.1 可调参数

| 参数 | 控件 | 范围 | 默认值 | 说明 |
|------|------|------|--------|------|
| 一级休眠时间 | 滑块 |0.5 ~ 30 分钟 | 0.5 分钟 | 无操作后进入低功耗状态 |
| 睡眠时间 | 滑块 | 1 ~ 60 分钟 | 20 分钟 | 无操作后进入深度休眠 |

### 8.2 说明

- **一级休眠**：鼠标降低采样率/灯光变暗，移动可唤醒
- **睡眠时间**：鼠标完全休眠，需按键唤醒，移动无法唤醒

### 8.3 XML 对应关系

```
电源管理容器：ms_4_ver_power_setting
一级休眠滑块：ms_4_slider_light_off（min=1, max=60）
睡眠时间滑块：ms_4_slider_sleep_timer（min=1, max=60）
一级休眠标签：ms_4_label_light_off
睡眠时间标签：ms_4_label_sleep_timer
```

## 十、宏管理器

### 10.1 界面布局

宏管理器窗口分为左右两个区域：

- **左侧面板**：宏列表，显示所有已保存的宏名称，可选中进行编辑
- **右侧面板**：当前选中宏的详细编辑区

### 10.2 宏列表管理

| 按钮 | 功能 |
|------|------|
| `+` | 新建宏 |
| `-` | 删除选中的宏 |
| 点击宏名 | 选中并加载到右侧编辑区 |

### 10.3 宏编辑区

**顶部控制栏：**
- 宏名称输入框：修改当前宏的名称
- 「鼠标动作」按钮：插入鼠标操作（左键/右键/中键等）
- 「录制」按钮：实时录制键盘/鼠标操作

**宏指令列表：**
表格形式显示每一步操作，包含三列：

| 列 | 说明 |
|----|------|
| 按键 | 对应的键盘按键或鼠标按钮 |
| 动作 | 压下（按下）或 释放（松开） |
| 延迟(ms) | 执行该动作后等待的毫秒数 |

每条指令支持编辑、上移、下移、删除操作。

**底部设置区：**

| 选项 | 说明 |
|------|------|
| 录制延迟 | 录制时自动插入的延迟模式 |
| 默认延迟 | 手动添加指令时的默认延迟值（单位 ms） |
| 最小延迟 | 录制时允许的最小延迟值（单位 ms） |

### 10.4 播放方式

每个宏支持 3 种播放方式（在按键绑定时选择）：

| 方式 | 说明 |
|------|------|
| 循环次数播放 | 按指定次数循环执行宏指令 |
| 任意键停止播放 | 按下任意键后停止当前宏播放 |
| 按住循环 | 按住按键时持续循环，松开停止 |

### 10.5 导出/导入

右下角的「导出」和「导入」按钮用于保存或加载宏配置到文件。

### 10.6 与按键绑定关联

宏本身不直接生效，需通过**按键设定**模块将宏绑定到某个按键：
1. 在按键设定中点击目标按键
2. 在功能菜单中选择「宏」→ 选择已创建的宏
3. 设置播放方式（循环次数 / 任意键停止 / 按住循环）
4. 点击应用后生效


### 10.8 XML 对应关系

```
宏列表：ms_4_macro_list
宏名称输入框：ms_4_edit_macro_name
宏指令列表：ms_4_macro_action_list
添加按钮：ms_4_btn_add
删除按钮：ms_4_btn_delete
鼠标动作按钮：ms_4_btn_mouse_event
录制按钮：ms_4_btn_record
默认延迟输入框：ms_4_edit_default_delay
导出按钮：ms_4_btn_export
导入按钮：ms_4_btn_import
```

## 十一、配置管理（Profile）

### 11.1 界面布局

配置管理窗口包含一个配置列表和底部操作按钮。

### 11.2 配置列表

显示所有已保存的配置方案，选中高亮显示。默认包含两个配置：

| 配置名称 | 说明 |
|---------|------|
| 日常 | 日常办公/普通使用配置 |
| 游戏 | 游戏场景配置 |

### 11.3 配置管理操作

| 按钮 | 功能 |
|------|------|
| `+` | 新建配置 |
| 垃圾桶 | 删除选中的配置 |
| 铅笔 | 编辑配置名称 |
| 上箭头 | 上移配置顺序 |
| 下箭头 | 下移配置顺序 |

### 11.4 配置内容

每个配置（Profile）保存了所有功能模块的当前值：

- DPI 数值（8 档 × 值 + 启用状态）
- 灯光模式 + 速度 + 移动关灯
- 回报率
- 按键映射（18 个 entry 的完整功能分配）
- 宏绑定关系
- 按键响应时间（去抖）
- 电源管理（一级休眠 + 睡眠时间）

### 11.5 切换方式

- **手动切换**：打开配置管理窗口，点击目标配置即生效
- **按键绑定**：在按键设定中可为某个按键分配「Profile 循环」、「Profile+」或「Profile-」功能

### 11.7 XML 对应关系

```
配置列表：ms_4_profile_list
添加按钮：ms_4_btn_add_profile
删除按钮：ms_4_btn_del_profile
编辑按钮：ms_4_btn_edit_profile
上移按钮：ms_4_btn_up_profile
下移按钮：ms_4_btn_down_profile
配置名称编辑：ms_4_edit_profile_name
配置列表项：ms_4_option_profile_N
```
